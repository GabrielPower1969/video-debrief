# 版式与设计约定

改 `assets/report_template.html` 之前先读这份。模板是自包含的：一段 `<style>`、
一段渲染脚本，不引任何外部 CSS/JS/字体/图片，所以离线打开、直接发给别人、
存进网盘都不会坏。加东西时请守住这条——一个 CDN 链接就能让报告在飞机上变砖。

## 结构

```
#theme               右上角固定的夜间/白天开关
header.hero          kicker / 短标题 / 原标题 / 一排 pill（平台·UP主·时长·字幕来源·语言）
.layout              248px 侧栏 + 正文，1200px 栅格；≤900px 折叠成单栏
  nav.toc            固定侧栏目录，IntersectionObserver 滚动高亮，右侧带条数
  main               00 总览 / 01 核心观点 / 02 章节时间轴 / 03 逐段精读 / 04 金句 / 05 完整转写
footer               生成时间、原视频链接、免责说明
#playerbar           底部固定播放条（毛玻璃）
#capbar > #cap       播放条上方浮动的实时字幕，可开关，状态存 localStorage
```

区块和目录项都是渲染时按数据动态生成的，编号 `00/01/02…` 自动顺延。
加新区块就调 `section(id, title, count)`，目录会自己跟上。

## 配色

| 变量 | 夜间值 | 用途 |
|---|---|---|
| `--bg` `--bg2` `--panel` `--panel-b` `--panel2` | `#0b0e14` `#090c12` `#141926` `#121722` `#1a2131` | 背景与面板层次（`--panel`→`--panel-b` 是面板的渐变两端） |
| `--ink` `--ink-soft` `--muted` | `#e9edf5` `#cbd3e2` `#9aa5bb` | 正文墨色 / 引文与原文 / 弱化文字 |
| `--brand` | `#5b9dff` | **只给交互元素**：▶ 按钮、当前目录项、激活行、字幕条左边框 |
| `--brand-soft` `--brand-line` `--brand-wash` | 同色低透明度 | ▶ 按钮底色/描边、激活行的横向渐变 |
| `--brand2` | `#8f7ff8` | 引用、主题标签、概述 callout |
| `--hl` | `rgba(246,183,60,.34)` | 重点标黄的荧光笔颜色 |
| `--good` `--warn` `--bad` | 绿 / 黄 / 红 | 保留给状态，别拿来当第 4 个系列色 |

数字瓦片和正文**不用数据系列色**：数值走正文墨色 + `tabular-nums`，标签走
弱化色。数字本身不是图表，给它上色只会让人以为不同颜色代表不同含义。

## 夜间 / 白天

夜间是默认，`:root[data-theme="light"]` 覆盖同一批变量切成白天，右上角
`#theme` 按钮切换，选择存 `localStorage['v2d-theme']`。首次打开跟随系统
`prefers-color-scheme`。

主题在 `<head>` 里由一小段内联脚本先落 `data-theme`，**必须留在渲染脚本之前**：
放到后面就会先画一屏深色再跳白，闪一下比不做还难看。

新增样式时守住一条：**颜色一律走变量**。写死一个 `#hex` 在夜间看不出问题，
到白天模式就是一块糊掉的色块。半透明的品牌色也别写死 `rgba(91,157,255,…)`，
用 `--brand-soft` / `--brand-line` / `--brand-wash`。

## 重点标黄

数据里写 `==这句话==`，渲染成 `<mark class="hl">`，效果是荧光笔压住下半截字
（`linear-gradient(180deg,transparent 52%,var(--hl) 52%)`），不是实心色块。

- 解析在 `fill()` 里，用 DOM 节点拼装，**全程不碰 `innerHTML`**，所以数据里
  带尖括号也只是普通文字。
- 只有 `elh()` 走解析——概述、观点标题与正文、章节标题与纪要。
  **引文和转写用 `el()`，逐字照抄**：原话里要是真出现 `==`，被吃掉就是篡改。
- 一段里最多黄一处。满屏黄等于没有重点，读者反而只能全文重读。

## 排版

- 非中文原文一律 `.en`（Georgia / 宋体，斜体）——和译文形成质感差异，扫一眼
  就知道哪句是原声。中文译文 `.zh`（弱化、`.94em`）。
- 时间相关数字全部 `font-variant-numeric: tabular-nums`，否则时间戳列会跳动。
- `body` 留 `padding-bottom: 84px` 给固定播放条；`body.no-audio` 时收回。

## 交互

- 所有播放按钮共用 `.pb` 类 + `data-t="秒数"`，事件是**文档级委托**，
  新增区块只要吐 `.pb` 就自动能播，不用再绑一次。
- 点击后按钮进入 `.playing`（▶ 变 ⏸），同时清掉其他按钮的状态。
- `timeupdate` 里用二分查找定位当前行（带上次命中的快速路径），
  更新字幕条 + 高亮转写行；「跟随播放自动滚动」勾选时 `scrollIntoView`。
- 无音频时给 `<body>` 加 `no-audio`：播放条与字幕条隐藏，`.pb` 变成不可点的
  纯展示标签。降级要静默，不要弹提示——没音频是正常情况，不是错误。

## 别做的事

- 别给 `.pb` 之外的元素加 `--brand` 底色。蓝色在这份报告里等于「可以点」，
  用在装饰上会让人乱点。
- 别把转写区做成整页铺开。它有 `max-height: 560px` 和自己的滚动条，
  否则一小时的视频会把报告拉成几万像素长，目录也就没意义了。
- 别删打印样式。有人会把报告 PDF 出来发给别人，那时候播放条、主题开关和
  按钮必须消失，而标黄要靠 `print-color-adjust: exact` 留下来——重点被打印机
  优化掉，这份 PDF 就白导了。
